## GitHub Pages

This site does not need a build step. In GitHub, enable Pages from the repository settings and choose:

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/root`

The site will publish as `https://<github-username>.github.io/<repo-name>/`.
